# MMIP 作業資料夾說明

本專案以週次區分每週的課堂作業，例如 `week1`、`week2`。每一個週次資料夾內，再依照當週的題目建立不同的 Quiz 資料夾，例如 `Quiz01`、`Quiz02`、`Quiz03`。部分 Quiz 的資料夾名稱會在編號後加入題目名稱，方便辨識該題的內容。

資料夾結構如下：

```text
weekN/
└── QuizXX_題目名稱/
    ├── AI/
    ├── Code/
    ├── Data/
    └── Output/
        └── report.md
```

## Quiz 內部資料夾

### AI

存放完成該題時使用 AI 工具的相關紀錄，例如使用的工具、協助內容及人工確認方式。AI 使用紀錄通常命名為 `AI_usage.md`。

### Code

存放該題的主要程式碼。程式會從 `Data` 讀取所需資料，執行資料處理、模型訓練或影像處理，並將產生的結果輸出至 `Output`。

### Data

存放程式需要使用的原始資料，例如 CSV、圖片或其他資料集檔案。若題目沿用前一題的資料，會在此資料夾放置說明文件，標示實際使用資料的位置。

### Output

存放程式執行後產生的結果，例如圖表、預測結果、評估指標、處理後的圖片與模型權重。

每一個 Quiz 的完整報告也會放在此資料夾中，檔名統一為 `report.md`。報告內容包含資料說明、使用方法、參數設定、實驗結果、檔案位置及結果分析。
