## 18．code_02｜程式能力

下列Python函式應計算整數list中嚴格大於0的元素數量，但目前有錯。請修正函式，保留名稱count_positive(values)，回傳整數且不可修改輸入list。


```python
def count_positive(values):
    count = 0
    for i in range(len(values) - 1):
        if values[i] >= 0:
            count += 1
    return count
```
