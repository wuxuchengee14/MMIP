# Quiz1：20題 Optimized Prompt 版本

本檔逐題列出完整優化提示，對應 benchmark.json 的 optimized_prompt。
每題保留原本任務與輸出限制，加入結構化提醒、輸出檢查，部分題目加入不同題目的few-shot示例。
這是優化提示候選版本，成效需與基本提示實測比較；技巧名稱仍應對照課程內容。

執行獨立JSON時必須加 --optimized，完整指令見 BENCHMARK_README.md。
