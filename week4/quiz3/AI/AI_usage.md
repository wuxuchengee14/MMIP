# Quiz 3 AI 使用紀錄

工具：OpenAI Codex。

協助內容：依使用者確認之作業要求設計 PyTorch 資料處理、模型、訓練／續訓、推論、指標、圖表、報告與執行腳本。

使用者確認：已確認三資料集與六模型的實作規劃，要求參考 GitHub MMIP 格式。

人工確認待辦：實際執行後閱讀結果，抽查資料分割、錯誤案例、生成描述、Gemini 理由及報告結論；不將 AI 撰寫視為人工已驗證。

參考：https://github.com/wuxuchengee14/MMIP
資料與 API 來源詳見根目錄 README.md 與 quiz1/Code/prepare.py。
