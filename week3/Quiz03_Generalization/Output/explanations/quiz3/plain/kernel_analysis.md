# 兩個訓練後 Kernel 的分析

選擇 Plain CNN 第一層的兩個固定 kernel，熱圖顯示權重，右側是同一張肝臟影像的卷積反應（ReLU 前）。
正負權重相鄰的結構可能對局部灰階差異或邊緣有反應；方向需結合反應圖判斷，不能視為已證實的器官偵測器。

- Kernel 0：權重平均 0.07571、標準差 0.16876；水平／垂直相鄰權重平均差 0.23697 / 0.25767。
- Kernel 1：權重平均 0.12407、標準差 0.17518；水平／垂直相鄰權重平均差 0.27162 / 0.24532。

請結合熱圖中正負區塊的排列，以及特徵圖中實際強烈回應的位置，描述兩個 kernel 的差異。
