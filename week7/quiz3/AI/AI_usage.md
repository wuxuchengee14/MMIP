# quiz3 AI 使用紀錄

工具：OpenAI Codex，依使用者提供的作業配分與已確認的模型／硬體條件協作。

LLM／VLM 偏好微調與影像條件比較。AI 自建規則標註 chosen/rejected 資料、實作 DPO＋LoRA，在 RTX 5090 實際執行正式訓練與前後測試，保留退步、重複與截斷回答。

數字來自 Output 的實際紀錄，沒有用論文成績或模擬資料冒充模型輸出。
Quiz 1／2 的商用模型名稱與日期為使用者填寫，沒有宣稱透過 API 或外部服務紀錄驗證。
Quiz 3 的偏好標籤由程式規則與繪圖物件清單產生，不是人工評分；方法為 DPO＋LoRA。
人工應核對題目、原始回答、標籤正確性、商用評語與方法限制。完成度代表證據涵蓋，評分由授課教師決定。
